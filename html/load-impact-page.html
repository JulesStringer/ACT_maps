ACT maps - Load impact data

This page loads impact data downloaded from Impact Tool onto the impact map.

This page has the following steps:

  1. Download parish impact data
  2. Download ward impact data
  3. Load CSV files and generate impact map data

When downloading data from this page you should select the following options:

Selection:Option to select
Geography:Parish
Individual Region:All
Footprint Type:Consumption
Scale:Per-household

You should then repeat the download, but with Geography: Ward
