Topic: Topic enables you to select a set of layers and themeing in one action. The base topic includes all available data. Zoom to: This enabled you to select a parish, that the map is then centred on and sized to fit the parish boundary. Summary on hover This checkbox controls what happens when the cursor hovers over a clickable feature on the map. If it is checked then a summary description of the current feature is displayed, otherwise the normal behaviour is to display a summary list of features at the cursor position when a click occurs on the map.
