Mapping Help

The mapping screen has the following components, click on the + button by each component to see what it does.

Toolbar

The toolbar is a row of controls at the top of the page, consisting of:

Topic

The topic allow you to control what layers are available for display on the map

Zoom to

The Zoom selection allows you to select a area, and zoom the map to display that area in a single action.

Summary on Hover

This checkbox controls what happens when the cursor hovers over a clickable feature on the map. If it is checked then a summary description of the current feature is displayed, otherwise the normal behaviour is to display a summary list of features at the cursor position when a click occurs on the map.

Help

This button displays the help menu, which consists of:

  • About - information about the current mapping software release
  • Mapping Help - This help information

Map

Help about the map

The map display consists of a background map with layers on top.

Layers displayed

Layers can be turned on and off by checking the box in the On column of the layer control to the right of the map.

Area displayed

The centre point of the map is changed by dragging the map (with your finger or by holding the left mouse button down, drag and release).

The map can be zoomed either with the +- buttons at the top left, of by using the scrollwheel on a mouse.

Feature Summary

When you select one or more feature on the map by clicking/tapping on them, a summary list of features is displayed, with a link for each feature.

If you then select the link, the feature's attributes will be displayed to the right (see attributes for more details).

The ability to select features is controlled by the checkbox in the clickable column of the layer control.

Coordinates

At the bottom left corner of the map the grid reference of the cursor position is displayed.

Layers

The layers control to the right of the map controls which layers are displayed on the map and has the following elements (from left to right)

ElementDescription
Expand GroupWhere layers have been grouped buttons with a + or - sign expand/collapse the list of layers in the group.
OnCheckbox which when checked causes a layer to be displayed.
ClickableCheckbox which when checked enables details of features in this layer to be accessible by a click on the map
RepresentationA sample of how the layer/theme is displayed on the map
Expand themesWhere a layer is themed using a condition on its attributes, this button with a + or - sign expands/collapses the list of themes for the layer.
DescriptionDescription of the layer / theme
Feature Details

When feature details are selected from the map these are displayed in the same area as the layer control

Title

At the top of the feature details display is a summary title, which corresponds with the feature summary displayed on the point clicked on the map.

Buttons

Below the title is a row of buttons top, print, close.

ButtonDescription
TopPuts the first row of the attribute display at the top of the attributes area (just below the buttons)
PrintPrints the current map together with an expanded view of the attributes of the current feature
CloseCloses the feature attributes window
Attributes

The remainder of the attributes window displays grouped attributes, the first of these groups (always called attributes) is displayed expanded, the rest are collapsed.

Where there is further information (metadata) about a named attribute, it has a tooltip, and a link to further information

Attributes

A table of names and attribute values, with where appropriate units to the right.

Other Attribute Groups

Other attributes are grouped. The expand (+/-) button expands collapses the group. The layout for each group defaults to the same name value format as ungrouped attributes, but some groups have a custom layout, which presents the data more accurately.
